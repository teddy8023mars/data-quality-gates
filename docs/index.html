Check hits ≠ distinct bad records

The same record can fail several checks. The dirty run has 12 check violations across just 3 distinct records: 2, 3 and 4.

Quality failure versus execution error

Parseable cells such as bad, NaN or a timezone-free timestamp fail quality checks: exit 1. Invalid contracts return config_error / 2; unreadable or malformed CSV returns input_error / 3. These errors do not produce a normal six-check evaluation.
